# PROJI — Change Management

1. Capture proposed change in a GitHub Issue or conversation.
2. Identify affected requirements, stage plans, dependencies, cost, security and operations.
3. Record approval or unresolved decision in DECISIONS.md.
4. Update PROJECT_REQUIREMENTS.md, PROJECT_ROADMAP.md, affected stage documents and Issues together.
5. Implement on a scoped branch and request review.
6. Test, record evidence, merge when approved and add a dated CHANGELOG entry.
7. Do not mark complete based solely on documentation or visual appearance.
