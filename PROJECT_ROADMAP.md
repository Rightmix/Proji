## Release gates
Stages 1–8 establish the ordering and operations MVP; validate recipe data and operational workflows before live orders. Stages 9–10 follow pilot learning where appropriate. Testing and security apply throughout, not only Stage 11. Do not mark any stage complete without passing documented acceptance criteria and recording evidence.

## Stage details
Each stage has a plan in docs/stages and a corresponding GitHub Issue. The Issue is the task tracker; this roadmap is the canonical cross-stage status summary. Changes must update affected requirements, issues, decisions and changelog.
